# MOVEVI 数据后台

面向经营管理者的 MOVEVI 业务数据后台高保真前端原型，覆盖数据概览、销售、设备、用户、跑遍全球、活动、商业和 AI 洞察等模块。

## 技术栈

- React 19
- TypeScript
- Vite
- React Router
- Recharts

## 本地运行

```bash
npm install
npm run dev
```

## 质量检查

```bash
npm run typecheck
npm test
npm run build
npm run test:sites
```

## 数据说明

当前版本使用统一模拟数据集，用于产品原型、业务口径确认和视觉评审，不连接真实生产接口。
